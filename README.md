# Simulación y Modelado de una Micro-red Híbrida

Este proyecto consiste en una simulación en MATLAB de una micro-red híbrida que integra generación solar, generación eólica y demanda eléctrica de una comunidad. El script analiza el comportamiento energético durante un día completo (24 horas) y presenta un balance entre generación total y consumo.

## Descripción del proyecto

La micro-red modelada considera tres componentes principales:

- Generación solar
- Generación eólica
- Demanda eléctrica de la comunidad

El objetivo principal es evaluar, hora por hora, si la red presenta:
- superávit energético,
- equilibrio,
- o déficit energético.

Además, se genera una gráfica comparativa entre la generación total y la demanda, facilitando la interpretación visual del comportamiento de la micro-red.

## Objetivo

Analizar el comportamiento de una micro-red híbrida durante 24 horas mediante una simulación basada en vectores de potencia, con el fin de:

- representar la generación solar,
- representar la generación eólica,
- calcular la generación híbrida total,
- representar la demanda de la comunidad,
- identificar superávit y déficit energético,
- visualizar los resultados en la consola y en una gráfica.

## Requisitos

Para ejecutar este proyecto se requiere:

- MATLAB
- Un entorno compatible con scripts `.m`
- No se requieren librerías externas ni dependencias adicionales

El repositorio contiene un único archivo principal:
